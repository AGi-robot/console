# Telepathy history

The `telepathic_management` package originated at `entity/telepathic_management` in [OppaAI/AGi](https://github.com/OppaAI/AGi). Its path-specific Git history is included in this repository as a parent history of the migration commit.

The imported commits retain their authors, dates, and messages. Their commit IDs differ from the original AGi history because the package directory was moved to the repository root. The original commits remain available in OppaAI/AGi.
